# 親機プログラム（同期制御）

本日（6月28日）作成・修正した親機プログラム一式です。

## 📁 フォルダ構成と概要

### 1. 修正版
- **概要:** モーターを実際に動かす機能が含まれているプログラムです。
- **注意:** 実機（メリーゴーラウンド）を回転させて動作させる際はこちらをベースにしてください。

### 2. main_hackathon
- **概要:** 6月28日の実験（タイマー駆動テスト）で使用したプログラムです。
- **注意:** モーターを回す機能がコメントアウトされているかもしれません。基本的には「修正版」のコードを参考にコメントアウトを外すか、「修正版」の方を使用してください。

---

## 🔌 BPM変化のための素子（可変抵抗など）について
もし本番までにテンポ可変用の素子（ポテンショメータ等）が手に入った場合は、`main` のコードを少し操作してください。
- アナログ入力で可変専用素子の値を読み取り、BPM（10〜60など）に反映させる設定を追加してください。

## 🚨 実行時のトラブルシューティング
- もし「修正版」にLEDの明滅制御機能がうまく入っていない（動かない）場合は、お手数ですが `main_hackathon` 側のコードから明滅制御のロジックを引用して移植してください。よろしくおねがいします。
